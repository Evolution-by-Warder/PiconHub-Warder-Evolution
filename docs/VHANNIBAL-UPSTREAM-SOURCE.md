# Vhannibal picon source

## Source role

https://www.vhannibal.net/

Vhannibal is **one of the external upstream sources** that may be used to discover and obtain current picons for Warder enrichment. It is not the sole picon source and it is not the authority for the Warder registry.

Other upstream/source layers may be used alongside Vhannibal, including preserved Chocholousek/Trezor material and additional sources approved for the project.

The final authority for identities, Warder IDs, accepted artwork and maintained output is the **Warder Master Registry and Warder QC/assimilation policy**.

## Vhannibal inputs

When Vhannibal is used as a source, the official landing page can be used to discover its current packages, including:

- current **Picon Vhannibal Motor** package — source artwork/candidates
- current **Vhannibal Motor** settings package — supporting metadata for matching services, service references, names, providers and satellite positions

Individual download URLs may change, so the stable landing page is recorded rather than pinning a transient package URL.

## Policy

- Vhannibal is source-only enrichment material, not Warder registry authority.
- Vhannibal is one possible picon source among multiple permitted sources.
- A new import should use the current upstream package when Vhannibal is selected as the source.
- Record observed upstream publication metadata and hashes of downloaded inputs in the import checkpoint.
- Never change an existing Warder ID merely because an upstream source changed.
- Never overwrite Warder production automatically.
- New or changed candidates must pass Warder matching/QC and required manual review before integration.
- Every approved batch must be committed as a durable checkpoint before continuing to the next batch.
