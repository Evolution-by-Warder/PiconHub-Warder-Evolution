# PiconHub-Warder-Evolution

Enigma2 picon project maintained by Warder.

## Repository layout

- `picons/` — picon database. Existing picons are preserved.
- `plugin/` — plugin source/package workspace based strictly on `enigma2-plugin-extensions-chocholousek-picons_5.0.240904_all.ipk`.

## Fixed project rule

The original plugin graphics and GUI structure are not to be redesigned or rearranged. Development is limited to approved branding, bug fixes and backend/functionality changes while preserving the original visual structure.

Current working package generation: `5.0.240904.2`.
