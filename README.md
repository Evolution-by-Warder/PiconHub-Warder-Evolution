# PiconHub-Warder-Evolution

**PiconHub-Warder-Evolution** is an Enigma2 plugin for downloading, updating and synchronizing channel picons for satellite TV and radio services. The project combines the Enigma2 plugin with the PiconHub picon repository and continues its development under Warder.

## Origins and credits

PiconHub-Warder-Evolution is based on the original **Chocholousek Picons** Enigma2 plugin created by **s3n0**.

The picon sets and the original picon work are by **Chocholousek**.

Full credit and thanks belong to **s3n0**, the author of the original plugin, and **Chocholousek**, the author of the picons on which this project builds. PiconHub-Warder-Evolution continues and evolves their work; it does not claim authorship of their original work.

## Repository layout

- `picons/` — PiconHub picon database.
- `plugin/` — Enigma2 plugin source, packaging and update workspace based on `enigma2-plugin-extensions-chocholousek-picons_5.0.240904_all.ipk`.

## Fixed project rule

The original plugin graphics and GUI structure are preserved and are not to be redesigned or rearranged. Development is limited to approved branding, bug fixes and backend/functionality changes while preserving the original visual structure.

## Development

Maintained and evolved by **Warder** as **PiconHub-Warder-Evolution**.

Current tested baseline: `5.0.240904.6`.
