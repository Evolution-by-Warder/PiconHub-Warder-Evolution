# PiconHub manifests v2

Canonical manifest layout:

```text
manifests/<satellite-position>/<provider>/<variant>.json
```

Examples:

```text
manifests/23.5e/skylink/transparent.json
manifests/23.5e/skylink/white.json
manifests/23.5e/skylink/black.json
manifests/0.8w/freesat/transparent.json
```

The previous provider-position directory convention is retired. Manifests will be regenerated against the v2 layout.
