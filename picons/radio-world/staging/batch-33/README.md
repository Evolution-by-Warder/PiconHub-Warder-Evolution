# Approved historical Radio PNG import – working only

600 previously approved references / 5,400 exact PNGs from 19 countries, recovered from three immutable saved archives and checked against the final checkpoint 28. No station artwork is rendered again. The whole input archives, every PNG hash and image dimensions are verified before use. Existing candidate/production bytes always win; divergent identities or artwork are held separately.

Binary source archives are to be attached to the private draft `radio-history33-working-source-20261106`; the draft must never be published as a production release. Only after all three SHA-pinned archives are uploaded, a small source-ready marker starts the working-branch importer. No Base64 chunks are used. Country candidates and a proposed 219-country index remain off production main pending owner approval.
