01 / L’esprit Service

Une radio.
Tout un souvenir.

Radio Service a accompagné les années 80 et 90 dans le Grand Sud. Cette webradio en retrouve l’esprit, avec une programmation fidèlement reconstituée et les jingles de l’époque.

La chaîne de traitement analogique a été remise en état pour retrouver cette couleur sonore : un son dense, chaleureux, immédiatement familier.

Comment garder Radio Service sur mon téléphone ?

Sur iPhone, ouvrez cette page dans Safari, touchez Partager puis « Sur l’écran d’accueil ». Sur Android, ouvrez le menu du navigateur puis « Ajouter à l’écran d’accueil » ou « Installer l’application » si l’option est proposée. Vous pouvez aussi enregistrer Radio Service en favori dans une application radio.

Je veux intégrer un petit lecteur sur mon site.

Copiez ce code dans un bloc HTML de votre site. L’intégration dépend des possibilités de votre hébergeur. Pour les réseaux sociaux, utilisez les liens illustrés ci-dessus.

Le direct ne démarre pas : que faire ?

Appuyez une nouvelle fois sur lecture. Si le problème persiste, essayez le lien « Flux direct » ou une application radio. Les navigateurs demandent une action de votre part pour démarrer le son ; la qualité de lecture dépend aussi de votre connexion et du serveur de diffusion.
