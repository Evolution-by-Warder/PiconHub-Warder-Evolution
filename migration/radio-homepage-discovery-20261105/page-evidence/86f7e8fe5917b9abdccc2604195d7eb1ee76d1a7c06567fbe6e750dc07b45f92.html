Comment écouter / How to listen Radio OCTOPUS

Via une radio internet ou un autre lecteur multimédia
Using a media player

Pour écouter Octopus sur une radio Internet ou un lecteur multimédia, utilisez les adresses suivante :
Use the following :

  • Qualité supérieure / High quality :
    http://media.radio-octopus.org:8000/192.mp3
  • Qualité normale / Normal quality :
    http://media.radio-octopus.org:8000/128.mp3
  • Qualité basse / Low quality :
    http://media.radio-octopus.org:8000/96.mp3
Via le site de la radio

Radio Octopus peut être écoutée à partir de notre site, grâce au lecteur situé en bas de la fenêtre du navigateur.

Via les sites TuneIn ou Orange Radio

Vous pouvez également écouter Radio Octopus en passant par le site TuneIn ou le site d'Orange Radio :



Il est possible que vous subissiez des coupures intempestives pendant la lecture. Cela est probablement dû à un défaut de connexion, si vous êtes trop loin de votre émetteur WiFi ou 3G, ou si votre connexion ADSL est trop faible. En choisissant un flux de moindre qualité, vous pallierez à ce défaut de débit.
