# Vhannibal picon import

This directory documents a one-time, guarded import of transparent 220×132 picons from **Picon Vhannibal Motor** into the maintained PiconHub database.

## Rules

- Canonical destination remains `picons/<satellite-position>/<provider>/transparent/<service-reference>.png`.
- No `satellite` wrapper directory and no `Satellite 0` placeholder are created.
- Satellite position is derived from the Enigma2 namespace in the service-reference filename.
- Provider is taken from the matching service record in Vhannibal Motor `lamedb`; provider names are normalized only for filesystem-safe folder names.
- Only valid PNG files with the project-standard size **220×132** are imported automatically.
- Picons with special/unknown namespaces, missing provider information, invalid filenames, or non-standard dimensions are skipped and recorded in the audit report.
- Existing PiconHub service-reference filenames are never overwritten.
- Only the `transparent` style is imported. White and black variants are not fabricated from the source images.

## Sources and credit

Picon source: **Vhannibal – Picon Vhannibal Motor** (`vhannibal.net`).

Provider/service metadata used only for classification: public `OpenVisionE2/Vhannibal-settings`, `vhannibal.motor/lamedb`.

The source picon collection itself credits multiple upstream picon projects/authors. PiconHub-Warder-Evolution does not claim authorship of those original graphics; this import only classifies and maintains them in the PiconHub hierarchy.

`import-report.tsv` and `import-summary.txt` are generated by the guarded importer and provide the audit trail for every accepted or rejected source PNG.
