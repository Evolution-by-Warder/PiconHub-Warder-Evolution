# CANAL+ provider logos

Approved provider branding assets for **CANAL+ CZ** and **CANAL+ SK**. Both market entries use the same official CANAL+ wordmark; separate paths preserve the requested provider names.

Each provider has transparent, white-template, and black-template variants at 220 × 132 px in RGBA PNG format. SHA-256 values and source details are in `manifest.json`.

The transparent artwork was prepared from the official CANAL+ logo source. White and black variants use the approved Warder master templates from the recorded template commit.

These files register provider branding. They do not replace Skylink assets or assign service-reference picons; runtime picons remain organized under `picons/<satellite-position>/<provider>/<variant>/<service-reference>.png`.
