# Released update payloads

For each published version place:

- `enigma2-plugin-extensions-piconhub-warder-evolution_<version>_all.ipk.parts`
- all base64 part files named by that manifest
- `enigma2-plugin-extensions-piconhub-warder-evolution_<version>_all.ipk.sha256`

Only after the complete payload is present should `../src/version.txt` be advanced to that version.
