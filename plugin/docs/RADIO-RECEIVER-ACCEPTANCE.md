# Radio picon receiver acceptance — OpenATV 8.x

Status: **not yet validated on a receiver**. Do not ship a production IPK.

## Required evidence

Collect anonymized examples of the following from a real receiver:

- `/etc/enigma2/userbouquet.*.radio` generated by a DAB+ scan.
- `/etc/enigma2/userbouquet.*.radio` containing a satellite DVB radio service.
- If available, FM/RDS and internet stream radio entries.
- The corresponding picon filenames actually requested by the radio list and HD Glass infobar (renderer logs or observed filenames).

Remove private stream credentials, local network addresses and access tokens before sharing. Preserve the first ten service-reference fields and the station's public name.

## Acceptance criteria

1. `sync_tv` matches its pre-feature behavior.
2. `sync_tv_radio` detects all playable, unambiguous service references.
3. The plugin does not delete existing icons in `sync_tv_radio`.
4. Ambiguous all-zero IPTV references do not cause one station's logo to be assigned to unrelated stations.
5. Real DAB+ references resolve to the correct station-specific logo.
6. Station-specific regional services (WDR/ARD/BR) are not incorrectly merged.
7. Picons appear both in the radio station list and HD Glass bottom infobar.
8. Archive source, artwork license and attribution are documented.
9. Automated tests and actual receiver test both pass before merge.

## Diagnostic commands (read-only)

```sh
grep -h '^#SERVICE ' /etc/enigma2/userbouquet.*.radio | head -60
find /usr/share/enigma2/picon -maxdepth 1 -type f -name '*.png' | head -30
```

These commands **only read** files. The picon path may differ with the user's plugin configuration.

## Privacy-safe diagnostics (feature branch)

The pure-Python `analyze_bouquet(contents)` helper returns `service_entries`, `accepted_unique`, `skipped_entries` and a sorted list of accepted picon reference stems. It does not return stream URLs, descriptions or station names. This is useful for comparing synthetic test bouquets with actual OpenATV output once anonymized samples are available.

The helper is **not yet wired to the receiver UI**. It is a developer diagnostic only, and cannot establish real DAB coverage or renderer compatibility by itself.
