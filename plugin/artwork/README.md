# Artwork used by the receiver plugin

- `templates/picons/`: frozen BLACK and WHITE MASTER PNGs; original bytes retained.
- `provenance/`: source, approval and import evidence for the plugin/shared skin picons; imported artwork authorship remains preserved.
- [QUALITY.md](QUALITY.md): artwork quality rules and reference checkpoint.

The canonical picon database remains at repository root `picons/` because both existing plugin versions and shared publication workflows depend on that address. These source files are not copied into the receiver IPK; the runtime uses the published skin-hosted package catalog.

Archived provenance documents can contain historical source paths and original archive inventories. They do not add extra choices to the current plugin. The active plugin supports the resolutions and backgrounds documented in [../README.md](../README.md).
