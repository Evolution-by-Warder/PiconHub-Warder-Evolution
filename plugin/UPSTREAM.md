# Upstream and attribution

PiconHub-Warder-Evolution intentionally preserves the history of the project it evolves from.

- **Chocholousek** created the original picon sets which are the historical picon foundation of this work.
- **s3n0** created and maintained the original **Chocholousek Picons** Enigma2 plugin used as the technical and GUI/workflow reference for this evolution.
- **Warder** maintains the PiconHub-Warder-Evolution line and its modernized backend.

The reference package used during the initial modernization was **Chocholousek Picons 5.0.240904**. The upstream package metadata identifies s3n0 as maintainer and GPLv2 as the license.

The new PiconHub engine is deliberately separated from the old `picon.cz` archive transport and points to this repository instead:

`https://github.com/Evolution-by-Warder/PiconHub-Warder-Evolution`

Original authorship notices must not be removed from code migrated directly from upstream.
