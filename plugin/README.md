# Plugin

Enigma2 plugin source for PiconHub-Warder-Evolution.

Runtime package:
`Plugins/Extensions/PiconHubWarderEvolution/`

The new engine reads picons from this repository's canonical structure:

`satellite -> provider -> style -> service-reference.png`

Example:
`picons/23.5e/skylink/transparent/1_0_...png`

See the repository root README for project overview and `UPSTREAM.md` for attribution.
