# Veľká integračná dávka – bezpečné plastické opravy

- Opravený opravný renderer: LOW_CONTRAST_WHITE/BLACK už nikdy nevytvorí ploché čierne/biele pozadie; zachová plastickú WARDER šablónu aj pri obrysovej oprave.
- Po opravnom renderi sa atomicky zapisuje SHA-256 podpis použitej šablóny. Plánovač tak nerozpozná platnú opravu ako starý neoverený render.
- Regresný test kontroluje nezmenené rohy šablóny, podpis a idempotentné opakovanie.
- Existujúce blokovanie finálnej QA zostáva aktívne. Autoupdate a bezpečné upratovanie stále nie sú kompletne integrované.
- Žiadny produkčný GitHub zápis ani mazanie originálov.
